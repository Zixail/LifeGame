# Игра «Жизнь» (Conway's Game of Life на C и OpenGL)

[![C](https://img.shields.io/badge/Language-C99-blue.svg)](https://en.wikipedia.org/wiki/C99)
[![OpenGL](https://img.shields.io/badge/Graphics-OpenGL_3.3-green.svg)](https://en.wikipedia.org/wiki/OpenGL)
[![License](https://img.shields.io/badge/License-MIT-brightgreen.svg)](LICENSE)

Интерактивная высокопроизводительная реализация клеточного автомата «Жизнь» Джона Конвея на языке C с собственным 2D-рендерером на базе OpenGL, GLFW и GLAD.

---

## Основные возможности

- Интерактивная симуляция: полный контроль над состоянием (пауза/возобновление), скоростью шагов, перемещением и масштабированием камеры.
- Детектирование осцилляторов и циклов: автоматический анализ истории состояний каждой клетки с подсвечиванием статичных фигур и осцилляторов красным цветом.
- Редактирование поля в реальном времени: добавление и удаление живых клеток кликами мыши (ЛКМ / ПКМ).
- Настраиваемый размер сетки: возможность задать размеры поля (X x Y) через интерфейс меню перед запуском.
- Встроенные шаблоны: мгновенная загрузка классических конфигураций (Глайдер, Квадрат, Мигалка, Пустое поле).
- Высокая производительность и экономия памяти: упакованные структуры данных на битовых полях, обеспечивающие минимальное потребление памяти и высокую локальность кэша для больших полей.
- Кастомный графический движок на OpenGL: рендеринг на базе шейдеров GLSL, динамическое обновление текстур и процедурное построение сетки.

## Управление и горячие клавиши

| Клавиша / Действие | Функция |
| :--- | :--- |
| **`W`, `A`, `S`, `D`** | Перемещение камеры по полю |
| **Колесико мыши** | Масштабирование (Zoom in / Zoom out) |
| **Левая кнопка мыши (ЛКМ)** | Добавить / нарисовать клетку |
| **Правая кнопка мыши (ПКМ)** | Удалить клетку |
| **`Space` (Пробел)** | Пауза / Запуск симуляции |
| **`Z`** | Уменьшить скорость симуляции |
| **`X`** | Увеличить скорость симуляции |
| **`F11`** | Полноэкранный режим |
| **`ESC`** | Выход в главное меню / Завершение |

## Архитектура проекта

```
LifeGame/
├── shaders/
│   ├── life.vert          # Вершинный шейдер для квада и сетки
│   └── life.frag          # Фрагментный шейдер для клеток и текстур
├── src/
│   ├── main.c             # Точка входа и главный цикл приложения
│   ├── life.c             # Логика симуляции и детектор циклов
│   ├── render.c           # OpenGL-пайплайн, обновление текстур и меню
│   ├── input.c            # Обработка ввода и управление камерой
│   └── glad.c             # Загрузчик OpenGL (GLAD)
├── include/
│   ├── life.h             # Определения битовых полей и API симуляции
│   ├── render.h           # Состояния рендера, VAO/VBO/EBO и шейдеры
│   ├── input.h            # Структуры камеры и ввода
│   └── ...                # Заголовки GLFW, GLAD и STB
└── img/                   # Текстуры интерфейса и шрифты
```

## Стек технологий

- Язык программирования: C (стандарт C99)
- Оконный менеджер и ввод: [GLFW](https://www.glfw.org/)
- Загрузчик OpenGL: [GLAD](https://glad.dav1d.de/)
- Шейдеры: GLSL (OpenGL 3.3 Core Profile)
- Загрузка изображений и шрифтов: `stb_image.h` / `stb_truetype.h`

## Сборка и запуск

### Требования

Убедитесь, что в системе установлен компилятор C (GCC/Clang) и библиотеки разработки GLFW3.

#### Для Ubuntu / Debian:
```bash
sudo apt update
sudo apt install build-essential libglfw3-dev libgl1-mesa-dev -y
```

### Компиляция

Сборка проекта с помощью `gcc`:

```bash
gcc -O3 src/*.c -Iinclude -lglfw -lGL -lm -o LifeGame
```

### Запуск

```bash
./LifeGame
```
